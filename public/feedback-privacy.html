Feedback privacy

Updated September 29, 2026 (a player counter; no bot-check widget). This notice covers the optional Feedback form in I'M DOG?. The game itself does not require an account.

What is shared

Your Comments are posted to an Issue in the public I'M DOG? GitHub repository. Anyone can read them. Please do not put contact details or other private information in Comments. An Issue reference ID, the submission time, how you played (keyboard and mouse, touch or controller) and the game version are also public; they help fix bugs and don't identify you.

What stays private

Name and email are optional. When you submit, the feedback service also receives your IP address, approximate country, browser user-agent, browser language, time zone, window size and submission time. These details are kept in a private Cloudflare database, not posted to GitHub Issues. The service uses them to handle feedback and limit abuse; the email may be used to reply. No precise location is requested.

To stop floods of automated submissions, the service limits how often one address can send feedback. Cloudflare (which runs the service) and GitHub process data under their own privacy terms.

Counting players

On im-dog.com the game also sends an anonymous signal when it has loaded, and another once someone has actually played for a little while. The service keeps only a daily total of each (how many visits and how many players), which it posts to a public "usage log" Issue in the repository. No name, identifier, cookie, IP address or device detail is stored for this: your address is used for a moment to limit how often the signal can be sent, and then forgotten.

How long it stays

Private feedback records are automatically deleted from the active database after 30 days. Cloudflare backups may follow Cloudflare's own retention rules. Public GitHub Issues remain until removed by the repository owner.

Your choices

You may leave Name, Email and Comments blank, or close the form without submitting. If you want to ask about or remove a submission before the 30-day deletion, send another Feedback form with “Privacy request for reference [your ID]” in Comments and provide an email privately if you want a reply. That request text will itself be public, so do not include private information in Comments.

If you are under 13, please ask a parent or guardian to send feedback for you.
